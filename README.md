# Customer Service Queue

## Project Description

Customer Service Queue is a console-based Java application
that manages customers waiting at a service counter.

The application uses a linked queue to maintain customers
in First-In-First-Out (FIFO) order.

## Features

- Join Queue
- Generate sequential tokens starting from Q101
- Call Next Customer
- Display Queue
- Leave Queue by Token
- Load customer records from a file
- Save customer records on exit

## Technologies Used

- Java
- Queue
- Linked List
- Node Class
- Objects and Methods
- File Handling

## How to Run

Compile the program:

javac CustomerServiceQueue.java

Run the program:

java CustomerServiceQueue

## Data File

Customer records are stored in customers.txt.
